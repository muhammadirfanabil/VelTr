# Personal Library App

A simple personal library application built with HTML, Tailwind CSS, JavaScript, and MongoDB.

## Features
- Admin: Add, edit, read, and delete books
- Guest: View and download books
- File upload and download functionality
- Simple authentication system

## Tech Stack
- Frontend: HTML, Tailwind CSS (CDN), Native JavaScript
- Backend: Node.js, Express.js
- Database: MongoDB
- File Storage: Local storage with Multer

## Getting Started
1. Clone the repository
2. Install dependencies (backend)
3. Set up MongoDB connection
4. Start the server
5. Open index.html in your browser
